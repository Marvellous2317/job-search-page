JobSearch is a sample job search platform built to demonstrate how modern web applications can help users discover job opportunities efficiently. The platform allows users to browse available jobs, search by keywords and location, view company details, and fill out a form to determine roles that best match their interests.

This project was created as a practical, real-world simulation for a client-style use case and as part of my portfolio to showcase frontend development skills using React.

Features
* Search jobs by title, keyword, and location
* View featured jobs and detailed job listings
* Company profile pages with open positions
* Job-fit form to guide users toward suitable roles
* Fully responsive, mobile-first design
* Clean and modern UI for great user experience

Tech Stack
* Frontend: React, HTML, CSS, Tailwind CSS
* Styling: Tailwind CSS
* Tooling: npm, Git, GitHub

Design Focus: Responsive layouts & usability
